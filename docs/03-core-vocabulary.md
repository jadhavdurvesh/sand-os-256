# 03 — Core vocabulary

**Status:** Provisional terminology  
**Architecture:** Caelvyr

| Project term | Intended meaning | Status |
|---|---|---|
| **Caelvyr** | SAND-256 machine architecture | Provisional codename |
| **Aru** | One 256-bit general-purpose scalar register | Proposed |
| **Aruvane** | The architecturally visible scalar-register organisation | Proposed |
| **Keth** | A decoded architectural instruction operation | Proposed |
| **Kethline** | An ordered sequence of encoded instructions | Proposed |
| **Orrenfold** | Experimental privileged kernel environment | Proposed |
| **Latticefire** | Reference execution model and trace engine | Proposed |
| **Veyrforge** | Assembler, linker, compiler and image-building workflow | Proposed |

## Naming rules

- Each term has one definition.
- Standard words such as register, opcode, pointer, page table, interrupt, and ABI remain available where they are clearer.
- A coined name never substitutes for a precise technical definition.
- Terms remain provisional until the relevant design is accepted.
- Names must be checked for collisions before stable public branding.

These names are project proposals, not claims of trademark uniqueness or legal exclusivity.
